# Changelog

What changed in each version, newest first, and what an existing installation must do about it.

## 0.1.0

First release as its own repository: blueprint, code-validation and qa-only, and the skills by other authors that I use beside them, each with its licence. These skills were developed and used in a private collection before; the history starts here.

Blueprint changes in this release: `rh.mjs --sync` copies design tokens from the path in `BLUEPRINT_TOKENS` instead of a fixed folder, the asd-ste100 linter is also found as the sibling skill in this repository, and feature queries split on letters of any language.
